Entrar no painel

O acesso usa uma chave do GitHub que só pode alterar o repositório do site. Ela fica guardada apenas neste navegador e só é enviada para api.github.com.

Como criar a chave (uma vez só)
  1. Abra github.com/settings/personal-access-tokens/new.
  2. Nome: Painel do site Movix. Validade: até 1 ano.
  3. Em Repository access, escolha Only select repositories e marque movix-site.
  4. Em Permissions: Contents = Read and write; Pages = Read-only.
  5. Clique em Generate token e cole a chave abaixo.
